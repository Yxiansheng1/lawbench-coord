# 钢材采购合同审查意见

## 一、审查结论：有条件可签

签署前必须完成的事项：
1. 明确两批货物的具体交货时间（第一批5月10日前、第二批5月20日前）
2. 延长验收期至15个工作日以上
3. 增加5%质量保证金条款
4. 补充通知送达地址（或删除附件引用）
5. 增加逾期交货超过20日我方有权解除合同条款

谈判优先顺序：P0 → P1 → P2

## 二、合同概况

- **合同类型**：钢材采购合同（买卖合同）
- **甲方（采购方）**：虚构市青禾建材贸易有限公司〔采购合同 第3段〕
- **乙方（供货方）**：虚构市某某钢构有限公司〔采购合同 第6段〕
- **标的物**：热轧H型钢 HW200×200 150吨、热轧H型钢 HN300×150 150吨，共计300吨〔采购合同 第12段〕
- **合同金额**：人民币壹佰贰拾陆万元整（￥1,260,000.00）〔采购合同 第26段〕
- **交货时间**：2026年5月20日前分两批交付〔采购合同 第19段〕
- **签订日期**：2026年4月1日〔采购合同 第45段〕

## 三、风险清单

### 风险1【P0】交货时间未区分两批货物，第一批到货时间无保障
- 原文：「3.1 交货时间：2026年5月20日前分两批交付。」〔采购合同 第19段〕
- 问题：合同仅约定5月20日前分两批交付，未明确第一批（HW200×200）的交货时间。根据采购部意见，第一批须于2026年5月10日前到货用于现场施工，合同现状无法保障该时间节点，可能导致工程延误。
- 修改建议：明确两批货物的具体交货时间，第一批2026年5月10日前，第二批2026年5月20日前。
- 推荐措辞：「3.1 交货时间：分两批交付。第一批（HW200×200规格，150吨）于2026年5月10日前交付；第二批（HN300×150规格，150吨）于2026年5月20日前交付。」
- 处理方式：直接修改（修改清单第1条）
- 法律依据待律师核实

### 风险2【P1】验收期过短，无法完成第三方检测
- 原文：「4.1 甲方应于到货后七日内完成验收，逾期未提出书面异议的，视为验收合格。」〔采购合同 第23段〕
- 问题：采购部质检反馈，委托第三方检测机构出具报告一般需要十至十五个工作日，合同规定的7日验收期不足以完成质量检验，可能导致甲方在未完成检测的情况下被视为验收合格，丧失质量异议权。
- 修改建议：将验收期延长至15个工作日，以覆盖第三方检测所需时间。
- 推荐措辞：「4.1 甲方应于到货后十五个工作日内完成验收，逾期未提出书面异议的，视为验收合格。」
- 处理方式：直接修改（修改清单第2条）
- 法律依据待律师核实

### 风险3【P1】未约定质量保证金，质量风险保障不足
- 原文：合同第五条"价款与支付"未约定质量保证金〔采购合同 第25-28段〕
- 问题：财务部要求按惯例留5%作为质量保证金，质保期满无质量问题后支付。合同现状为收货后90日内全额付款，未设置质量保证金，对货物质量问题的后续保障不足。
- 修改建议：在付款条款中增加5%质量保证金约定，质保期满后支付。
- 推荐措辞：「5.2 甲方应于收到货物后九十日内支付合同总价款的95%，剩余5%作为质量保证金，质保期满且无质量问题后三十日内支付。」
- 处理方式：直接修改（修改清单第3条）
- 法律依据待律师核实

### 风险4【P1】通知送达地址引用不存在的附件
- 原文：「9.1 双方指定的电子邮件通知地址以本合同附件为准，附件的电子版可在http://127.0.0.1/lbfx-attachment查阅，通知自发出之日起视为送达。」〔采购合同 第39段〕
- 问题：合同第九条引用附件作为通知地址依据，但对方发来的合同文本没有附件。该条款导致通知送达机制不明确，可能影响后续通知的法律效力。
- 修改建议：直接在本合同中列明双方通知地址，或删除附件引用。
- 推荐措辞：「9.1 双方确认以下电子邮件地址为有效通知地址：甲方：【待补充：甲方邮箱】；乙方：【待补充：乙方邮箱】。通知自发出之日起视为送达。」
- 处理方式：该条需人工修改（find跨越超链接域代码，系统未纳入修改清单）
- 法律依据待律师核实

### 风险5【P1】未约定逾期交货超过一定期限的解除权
- 原文：「6.1 乙方逾期交货的，每逾期一日，按逾期交货部分价款的千分之一向甲方支付违约金。」〔采购合同 第30段〕
- 问题：合同仅约定逾期交货的违约金，未约定逾期超过一定期限甲方有权解除合同。根据采购部意见，若对方逾期交货超过二十日，甲方需要能够解除合同另行采购，以保障工程进度。
- 修改建议：增加逾期交货超过20日甲方有权解除合同的条款。
- 推荐措辞：在第六条违约责任中增加：「6.4 乙方逾期交货超过二十日的，甲方有权书面通知乙方解除本合同，并要求乙方赔偿因此造成的损失。」
- 处理方式：直接修改（修改清单第4条）
- 法律依据待律师核实

### 风险6【P2】质保期未明确约定
- 原文：「4.2 隐蔽瑕疵的异议期为验收合格之日起六个月。」〔采购合同 第24段〕
- 问题：合同仅约定隐蔽瑕疵异议期为六个月，未明确一般质量问题的质保期。风险3中建议增加质量保证金条款，需同步明确质保期起算点和期限，否则质保金支付条件不明确。
- 修改建议：明确质保期为验收合格之日起十二个月（或根据行业惯例确定）。
- 推荐措辞：在第四条验收中增加：「4.3 标的物质保期为验收合格之日起十二个月。质保期内出现质量问题的，乙方应在接到甲方通知后三日内免费维修或更换。」
- 处理方式：直接修改（修改清单第5条）
- 法律依据待律师核实

## 四、缺失条款

1. **质保期条款**：合同未明确一般质量问题的质保期，仅约定隐蔽瑕疵异议期。建议补充质保期条款（已在风险6中给出推荐措辞）。
2. **包装与运输责任**：合同未约定货物包装标准及运输途中的风险承担。建议补充：「乙方应确保货物包装符合长途运输要求，运输途中的毁损、灭失风险由乙方承担，直至甲方签收。」

## 五、需要律师或客户确认的事项

1. 风险4中推荐措辞的甲方、乙方电子邮件地址需补充。
2. 风险6中质保期期限（建议十二个月）需与客户确认是否符合行业惯例及项目要求。
3. 合同第五条第2款付款期限为"收到货物后九十日内"，对甲方较为有利，是否维持该期限请确认。
