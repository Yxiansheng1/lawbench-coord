# 钢材采购合同审查意见

## 一、审查结论：有条件可签

签署前必须完成的事项：
1. 明确两批钢材各自的交货时间（第一批HW200×200须于2026年5月10日前到货）；
2. 增加逾期交货超过二十日我方可解除合同的权利；
3. 延长验收期限至十五个工作日，或改为"以第三方检测报告出具之日为准"；
4. 补充第九条所称附件，或在正文中直接写明双方通知地址；
5. 增加5%质量保证金条款。

谈判优先顺序：P0 → P1 → P2

## 二、合同概况

- 合同类型：钢材采购合同〔采购合同 第1段〕
- 甲方（采购方）：虚构市青禾建材贸易有限公司〔采购合同 第3段〕
- 乙方（供货方）：虚构市某某钢构有限公司〔采购合同 第6段〕
- 标的物：热轧H型钢HW200×200（150吨）、热轧H型钢HN300×150（150吨）〔采购合同 第12段〕
- 合同总价：人民币壹佰贰拾陆万元整（￥1,260,000.00）〔采购合同 第26段〕
- 交货时间：2026年5月20日前分两批交付〔采购合同 第19段〕
- 付款方式：收到货物后九十日内付款〔采购合同 第27段〕

## 三、风险清单

### 风险1【P0】交货时间未区分批次，与项目进度要求不符
- 原文：「3.1 交货时间：2026年5月20日前分两批交付。」〔采购合同 第19段〕
- 问题：采购部明确要求第一批HW200×200（150吨）须于2026年5月10日前到货，第二批HN300×150（150吨）须于2026年5月20日前到货〔采购部内部意见 第5-6行〕。合同仅约定5月20日前分两批交付，未区分批次时间，乙方可能将两批均安排在5月20日前任意时间交付，导致第一批钢材无法按时进场，影响虚构市某某厂房项目进度。
- 修改建议：将交货时间条款修改为分批次明确时间。
- 推荐措辞：「3.1 交货时间：第一批HW200×200热轧H型钢150吨，须于2026年5月10日前交付；第二批HN300×150热轧H型钢150吨，须于2026年5月20日前交付。」
- 处理方式：直接修改（修改清单第1条）
- 法律依据待律师核实

### 风险2【P0】缺乏逾期交货的解除权
- 原文：「6.1 乙方逾期交货的，每逾期一日，按逾期交货部分价款的千分之一向甲方支付违约金。」〔采购合同 第30段〕
- 问题：合同仅约定逾期违约金，未赋予甲方在乙方严重逾期时的解除权。采购部要求：对方逾期交货超过二十日的，我方需要能够解除合同另行采购〔采购部内部意见 第10行〕。若乙方逾期超过二十日，甲方只能继续等待并收取违约金，无法另行采购，可能造成项目重大延误。
- 修改建议：在违约责任条款中增加逾期超过二十日甲方可解除合同的权利。
- 推荐措辞：「6.1 乙方逾期交货的，每逾期一日，按逾期交货部分价款的千分之一向甲方支付违约金。乙方逾期交货超过二十日的，甲方有权解除本合同，并要求乙方赔偿由此造成的损失。」
- 处理方式：直接修改（修改清单第2条）
- 法律依据待律师核实

### 风险3【P1】验收期限过短，无法完成第三方检测
- 原文：「4.1 甲方应于到货后七日内完成验收，逾期未提出书面异议的，视为验收合格。」〔采购合同 第23段〕
- 问题：质检部反馈，委托第三方检测机构出具报告一般需要十至十五个工作日，到货后七日内无法完成验收〔采购部内部意见 第7行〕。若按合同第七条执行，甲方在七日内无法完成检测，将被动视为验收合格，丧失对质量问题的异议权。
- 修改建议：将验收期限延长至十五个工作日，或改为以第三方检测报告出具之日为准。
- 推荐措辞：「4.1 甲方应于到货后十五个工作日内完成验收，逾期未提出书面异议的，视为验收合格。甲方委托第三方检测机构检测的，验收期限自检测报告出具之日起算。」
- 处理方式：直接修改（修改清单第3条）
- 法律依据待律师核实

### 风险4【P1】缺少质量保证金条款
- 原文：「5.2 甲方应于收到货物后九十日内付款。」〔采购合同 第27段〕
- 问题：财务部意见要求货款按惯例留5%作为质量保证金，质保期满无质量问题后支付〔采购部内部意见 第8行〕。合同未约定质量保证金，全部货款在收货后九十日内付清，甲方对后续出现的质量问题缺乏制约手段。
- 修改建议：增加质量保证金条款，明确5%保证金的扣留和支付条件。
- 推荐措辞：「5.2 甲方应于验收合格后九十日内支付合同总价款的95%。合同总价款的5%作为质量保证金，在质保期满且无质量问题后三十日内无息支付。」
- 处理方式：直接修改（修改清单第4条）
- 法律依据待律师核实

### 风险5【P1】合同引用附件但附件缺失
- 原文：「9.1 双方指定的电子邮件通知地址以本合同附件为准，附件的电子版可在http://127.0.0.1/lbfx-attachment查阅，通知自发出之日起视为送达。」〔采购合同 第39段〕
- 问题：合同第九条明确通知地址"以附件为准"，但对方发来的文本没有附件〔采购部内部意见 第9行〕。附件缺失导致通知送达地址不明确，可能影响后续通知的法律效力。
- 修改建议：在合同中直接写明双方通知地址，或删除"以附件为准"的表述并补充具体地址。
- 推荐措辞：「9.1 双方指定的通知地址如下：甲方：虚构省虚构市虚构区不存在大道100号，联系人：冯某，电话：【待补充】，邮箱：【待补充】；乙方：虚构省虚构市虚构区无此路200号，联系人：褚某，电话：【待补充】，邮箱：【待补充】。通知自发出之日起视为送达。」
- 处理方式：该条需人工修改（原文含超链接，系统修改清单无法处理）
- 法律依据待律师核实

### 风险6【P2】付款条件未与验收合格挂钩
- 原文：「5.2 甲方应于收到货物后九十日内付款。」〔采购合同 第27段〕
- 问题：付款条件为"收到货物后"，而非"验收合格后"。若货物存在质量问题但甲方未在验收期内提出异议，仍需付款；且与风险4的修改建议需协调。
- 修改建议：将付款条件修改为"验收合格后"。
- 推荐措辞：已在风险4的推荐措辞中一并修改为"验收合格后九十日内支付合同总价款的95%"。
- 处理方式：与风险4合并修改（修改清单第4条）
- 法律依据待律师核实

### 风险7【P2】交货通知期过短
- 原文：「3.3 乙方应提前两日通知甲方收货，甲方应安排人员清点签收。」〔采购合同 第21段〕
- 问题：提前两日通知可能不足以让甲方安排仓库、人员和运输设备，特别是大批量钢材到货时。
- 修改建议：将通知期延长至三至五日。
- 推荐措辞：「3.3 乙方应提前三日通知甲方收货，甲方应安排人员清点签收。」
- 处理方式：直接修改（修改清单第6条）
- 法律依据待律师核实

## 四、缺失条款

1. **质保期条款**：合同未约定质保期。建议在质量标准条款中增加：「标的物质保期为验收合格之日起十二个月。质保期内出现质量问题的，乙方应在接到甲方通知后三日内免费维修或更换。」
2. **包装与运输条款**：合同仅提及单价含运输费，未约定包装标准和运输风险承担。建议增加：「乙方应按国家标准对标的物进行包装，确保运输安全。标的物毁损、灭失的风险自甲方签收之日起转移至甲方。」
3. **保密条款**：合同未约定保密义务。如双方对价格、数量等信息有保密需求，建议补充。

## 五、需要律师或客户确认的事项

1. 质保期期限：建议十二个月，请确认是否符合行业惯例和项目要求。
2. 通知地址和联系人信息：合同附件缺失，需在修改时补充双方具体通知地址、联系人、电话和邮箱（目前标为【待补充】）。
3. 争议解决条款：合同约定提交甲方所在地人民法院诉讼解决〔采购合同 第37段〕，对我方有利，无需修改。
4. 违约金标准：乙方逾期交货违约金为日千分之一，甲方逾期付款违约金为日万分之五，双方标准不一致，对我方相对有利，可维持现状。
