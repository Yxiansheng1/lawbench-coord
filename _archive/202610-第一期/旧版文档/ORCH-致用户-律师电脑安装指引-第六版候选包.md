## 1. 装之前看三样

1. **系统**：Windows 10/11 64 位。磁盘至少留 3 GB。
2. **智能应用控制**（只有全新出厂的 Win11 才默认开）。管理员 PowerShell：
   ```powershell
   Get-CimInstance -Namespace root\Microsoft\Windows\Defender -ClassName MSFT_MpComputerStatus | Select-Object SmartAppControlState
   ```
   - `Off` 或命令报错 → 直接装。
   - `On` 或 `Eval` → 这台机现在装不了（第三方组件未签名会被拦）。要装只能在"设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制"里关掉，**关了不能再开**，须律师本人同意。等代码签名证书办下来（N73）就不需要这一步。
3. **Word**：装了更好（旧格式转换、兼容模式导出用），没装也能用。

## 2. 安装

1. 双击安装包。Windows 可能弹"Windows 已保护你的电脑"（因为没签名）→ 点"更多信息" → "仍要运行"。
2. 一路下一步，默认装到 `C:\Users\<律师>\AppData\Local\Programs\连越律师工作台`。
3. 装完会问一次"是否创建律所统一 Skill 目录？"→ 选**否**（律所统一 Skill 还没下发，以后由 IT 一条命令建）。
4. 开始菜单、"应用和功能"里都叫"连越律师工作台"。

## 3. 首次配置（程序第一次打开自动弹）

| 项 | 填什么 |
|---|---|
| 律师姓名 | 本人姓名（必填） |
| 6000D 所内 / 所外 | `http://192.168.8.77:8000/v1` / `http://10.126.126.1:8000/v1`（页面已预填，不用改） |
| 395 所内 / 所外 | `http://192.168.8.124:9000` / `http://10.126.126.3:9000`（页面已预填，不用改） |
| 6000D Key | 由你**当面或电话**给每位律师，**不要写进微信/邮件/任何文件** |
| 日常办公文件夹 | 默认 `文档\连越律师工作台`，不用改 |

填完点"测试连接"，两台都显示"已连接（所内）"即可保存。所内所外程序会自动切换，律师不用管。

**所外使用**：律师电脑还要另装 EasyTier 并加入律所虚拟网（每台设备一把钥匙，由你发）。这一步还没铺开（A2/A3 待定），**第一批先只在所内用**。

## 4. 装完验一下（2 分钟）

1. 启动后主窗口标题"连越律师工作台"，**没有**"启动检查发现 N 个问题"的提示。
2. 首页能看到"日常事务"，三个主按钮都在。
3. 新建一个案件 → 导入一份 PDF → 等识别完 → 问一句"这份材料讲了什么" → 有回答、能点出处看原文。
4. 右下角有"上海莫来特智能科技有限公司"字样。
5. 首页"日常事务"卡片里有"工具"一栏（长截图切分、格式互转），开始菜单里也有这两项。

## 5. 常见情况

| 现象 | 处理 |
|---|---|
| 启动提示"本机服务未能启动：…应用程序控制策略已阻止此文件" | 智能应用控制是开的，见第 1 节第 2 条 |
| 启动提示"本机 18765 端口被其他程序占用" | 这台电脑有别的程序占了端口，关掉它再开工作台；不知道是哪个就重启电脑 |
| 启动提示"本机服务未能启动：<别的原因>" | 把提示原文截图发你，转开发 |
| "测试连接"失败 | 先确认电脑在律所网络里；再看地址有没有多打空格；Key 填错时 6000D 那项会明说 |
| 新建案件时提示"这个文件夹会被云盘同步" | 点"为我在本机建一个文件夹"即可（案件默认放在 `C:\Users\<名>\连越律师工作台`，不进 OneDrive） |
| 点"开始"前提示"材料较长" | 一次最多读全约 11 份/100 页；可以"仍然开始"，没读全的会在成果上标出；更稳的做法是分批或缩小本次范围 |
| 要卸载 | "应用和功能"里卸载，案件文件在"文档"里不会被删 |
| 要升级到新版 | 直接装新包覆盖，不用先卸载，设置和案件都保留 |
