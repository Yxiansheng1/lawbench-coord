# 连越律师工作台 · 更新说明（第七版，2026-10-10）

## 怎么升级

**Windows**：关闭工作台（右下角托盘图标右键"退出"），双击新安装包，一路下一步。不用卸载，案件、设置、Key 都保留。
**Mac**：退出工作台（顶部菜单栏"连越律师工作台"→"退出"），双击新的 dmg，把三个图标拖进"应用程序"，选"替换"。案件和设置都保留。

## 这版新增

| 您反映的 | 现在 |
|---|---|
| 电脑上已经整理好的案子文件夹，想一步拖进来 | 把整个文件夹**拖到首页空白处**（案件卡片以外的地方），松手前会显示"松开：建新案件"，松手后问您一句"把『××』建成案件？"选民商事 / 刑事 / 日常事务，确定即成。文件夹**原地不动、不复制**，里面的文件直接就是材料 |
| 左栏"添加案件"选了文件夹却不能用 | 现在左栏的"添加案件"（也可按 Ctrl+O）选完文件夹后，和拖到首页空白处一样：问一句"建成案件？"，确定后登记、识别材料、进入案件 |
| 拖案件和拖材料怎么区分 | 看拖到哪里：拖到**首页空白处**是建案件；拖到**某个案件的卡片上**、或案件里的材料栏，是往那个案件加材料（和以前一样）。两种情况高亮颜色和提示文字不同，松手前就看得出 |
| 材料做了 Word，名字里带逗号就打不开 | 已修。名字含逗号、等号的文件和文件夹都能"打开"和"打开所在文件夹" |
| 服务起不来只说"端口被占" | 现在分三种话：真被别的程序占了 → 请关掉那个程序；端口在 Windows 自己的保留段里（装过虚拟机、WSL 的电脑常见）→ 不是被占，关程序没用，请联系技术支持换端口；系统拒绝 → 请联系技术支持 |
| 新建案件自动建很多子文件夹 | 新建时弹框勾选要哪些，默认一个都不勾，也可以自己填名字 |
| 案件概览分成六张小卡片 | 合成材料页顶部一张卡，一次"核对完成"，可以直接打开 wiki 文件夹和各篇文件 |
| 从 OneDrive 等云盘文件夹里导入材料被拒 | 已放开：云盘里的文件可以导入（只是复制进本机案件）；案件本身仍不能放在云盘文件夹里 |

还有一处是服务器侧、不用升级就已生效：**扫描件识别换了新模型**，带水印的页面不再识别出一堆乱字，每页约 5 秒（原来 26 秒），表格能识别成表格。识别结果里不会出现页眉页脚（案号、页码），这是模型的工作方式，引用页码按文件页序标注不受影响。

## 几点说明

- 拖**单个文件**到首页空白处不会建案件（一个文件不成案），请拖到某个案件卡片上，或先新建案件。
- 文件夹如果在 OneDrive 等云盘里，拖进来会提示，并给一个"复制到本机建案件"的按钮。
- **"移除此材料"按钮仍是灰的**，下一版放开（删掉的文件进回收站，不永久删除）。

## 遇到问题

启动时的提示文字、界面上的报错，截图发给安装负责人即可；我们看日志只有时间和状态，不含材料内容。
