# 连越律师工作台 · 更新说明（第六版，2026-10-07）

## 怎么升级

关闭工作台（右下角托盘图标右键"退出"），双击新安装包，一路下一步。**不用卸载**，案件、设置、Key 都保留，装完直接进首页。

## 这版新增

| 您反映的 | 现在 |
|---|---|
| 小工具找不到 | 首页"日常事务"卡片里有"工具"一栏：**长截图切分**、**格式互转**；开始菜单里也有这两项 |
| 材料放在哪、成果怎么导出 | 右栏"材料""成果"各有**"打开所在文件夹"**，一键打开本机文件夹；成果照旧可"导出 Word" |
| 新建案件总提示"云同步目录" | 案件默认放在 `C:\Users\<您的用户名>\连越律师工作台`（不进 OneDrive）；再遇到提示，点**"为我在本机建一个文件夹"**即可 |
| 材料长了读不全、事后才知道 | 点"开始"前会先估算：超过一次能读全的量（约 11 份或 100 页）就提示"材料较长"，可以继续，也可以分批或缩小范围；成果上仍会标出没读全的材料 |
| 服务起不来只说"未启动" | 现在会说原因，比如"18765 端口被其他程序占用"，照提示处理即可 |

另外：安装包小了 118 MB；与原版 DeepSeek Harness 装在同一台电脑互不影响。

## 还没有的（已记录，后续版本）

- **"移除此材料"**按钮现在是灰的：删掉文件后检索里还会留着它的文字，等服务端加了删除功能再放开；现在要删，到文件夹里删掉后点"重新扫描"，材料会标为"原件已删除"。
- 去水印不在工作台里，那是律所另一个工具。
- 一次任务能读的材料总量有上限，长卷宗请分批。

## 遇到问题

启动时的提示文字、界面上的报错，截图发给安装负责人即可，不用描述操作细节；我们看日志只有时间和状态，不含材料内容。
