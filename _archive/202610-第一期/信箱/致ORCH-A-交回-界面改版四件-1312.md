## 四条做法

1. **律所 logo**：侧栏品牌位常驻，在产品名左侧，按 22 px 显示，满高时底下一行被切；空白会话大标题旁也换成律所 logo。
   - 图由 `make_brand.py` 新增的 `ui_assets` 生成 `dsh-ext\ui\brand-assets.ts`（data: URI）。原件不改，其余品牌素材重跑后逐字节不变。
2. **技术公司"上海莫来特智能科技有限公司"**，常驻三处：
   - 侧栏底部一行带小标志；
   - 首次配置页底部（P-3）；
   - 设置页"关于"。
   - DSH 自带关于面板的名称改为"莫来特"（P-4）。**英文名 `Shanghai Morelite …` 没有依据，没改，候用户。**
   - `check_ui_words.py` 对全名零误伤，没加允许项。
3. **两层胶囊放到输入框上方**：
   - 空会话从上到下：分流提示 → 第二层"<分类> · 选要做什么" → 第一层"能力入口"（选中高亮）。点第二层出小标签【名称】（× 取消），走原任务单写法，N37/N51、`sheetHold` 不变。
   - 原胶囊下拉框并进这一套；会话有内容后收起，点"选能力"展开；工具胶囊仍开 T26 页面。
   - 取消单独首页：启动直接是对话区；侧栏入口改为"案件：<当前案件名>"，点开是最近案件、新建、打开、切换。胶囊管理挪到设置页。
   - 效果图里 DSH 原版的"工作区 ▾ / 标准模式 ▾"、模型选择没加。
4. **日常事务**：
   - Host 新方法 `dailyCase`：首次配置做完后第一次问到时，在"日常办公文件夹"下建 `日常事务\`；设置为空用 `文档\连越律师工作台`，并写回设置。走 `/api/case/open` 登记，`template` 为 null。之后按记下的位置返回；文件夹不在时不重建，按 T17 `CASE_MOVED`。
   - 界面启动时取到它、读到案件列表后，若当前会话不在案件里就打开它，空会话可直接发送。
   - 服务侧（T3）不需要改。
