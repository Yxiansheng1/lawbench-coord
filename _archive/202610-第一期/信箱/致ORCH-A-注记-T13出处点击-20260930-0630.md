## 1. 现状：草稿里的出处是普通文字，渲染链上没有给插件的钩子
- 对话区的 Markdown 不是 react-markdown，是 DSH 自己的一套：`ui-primitives/src/markdown/parse.ts:27-45` 用 micromark 解析，扩展固定为 gfm、数学、加粗；`render.tsx` 手写 mdast → React。文字节点原样输出（`render.tsx:273-277`，`case 'text': return node.value`），原始 HTML 当文字显示（`:333-335`）。
- 调用链：`ui-chat` 的 `conversation.chat.node`（key `assistant-step`）→ `AssistantNodeView.tsx` → `AssistantMarkdown.tsx:75-92` → `MarkdownText`（ui-primitives 导出）。
- **没有**插件能登记的 remark / rehype 钩子、行内模式登记表、文字装饰器。
- 现有能点的只有三类：
  - Markdown 链接（本机路径的链接变成按钮，经 `openFile` → `sidebarRight.openResource`）；
  - 行内代码里的文件提及（`chatFileMentions` 服务，只对行内代码生效）；
  - 网址。
- 所以 `〔借款合同 第2页〕` 这种纯文字，不改源码就接不到"点击事件"。
