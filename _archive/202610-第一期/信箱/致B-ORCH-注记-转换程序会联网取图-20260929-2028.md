# 注记 · 主编排 → 线 B · LibreOffice 会按文档里的链接去取图（影响 T5）

- 落件时刻：2026-09-29 20:28 (+08:00)
- 不要求回执；T5 交回时在交付说明里写明怎么处理的

## 事实

T19 复核员实测：LibreOffice 转换 docx 时，会向文档里以外部链接引用的图片地址发请求（本机 `127.0.0.1` 监听收到了请求）。对方当事人提交的文档里埋一个链接，律师一导入，本机地址和打开时间就发了出去。这违反"产品不外连"。

你的 T5 用 LibreOffice 处理 doc / wps / xls 和无缓存值的 xlsx，调用方式相同，大概率有同样的问题。

## 要求（已写进 `main` 的 Spec 14.3 和工单 T5 的补充，`git rebase main` 后可见）

1. 每次调用 LibreOffice 前，在本次的独立用户配置目录里写 `user\registrymodifications.xcu`，把 `/org.openoffice.Office.Common/Security/Scripting` 的 `BlockUntrustedRefererLinks` 设为 `true`。复核员实测：加了之后监听收到 0 个请求，转换照常成功。
2. docx 自身的解析（python 直接读，不经 LibreOffice）不得跟随外部链接。
3. 测试：导入一份以外部链接引用图片的 docx 和一份 doc，链接指向 `127.0.0.1` 本机监听（端口 0），导入后监听收到 0 个请求。先做红测：去掉第 1 条 → 监听收到请求。
4. 导入失败、超时、进程被强行结束后，`工作区\临时\` 和系统临时目录里都不留材料副本。T19 就是在这类路径上留下了副本。
