## 做法

1. **对齐**：输入区上方各行放进同一个外框，宽度 = 容器宽减两侧留白，最多到输入框最大宽，居中。这些宽度量取自 DSH 输入框自己的 CSS 变量，所以与输入框同边缘、同宽。行距统一 10 px，字号大一级。
2. **概览卡**：
   - 内容：案件名；材料 N 份（其中待识别 M 份）；最近 3 条成果；最近一次对话；都可点开。
   - 数据走现有 `materialsList`、`outputsList` 和 DSH 会话列表，没加接口。
   - 日常事务换成提示句＋最近 3 条对话。
3. **右栏默认展开**：打开案件或日常事务时，开好材料、成果、原文查看并停在材料。每个会话只开一次，之后折叠、关标签由 DSH 按会话记住。
4. **命名清理**：
   - 输入框上的权限档开关（"工作区内修改"）藏掉：我方在同一位置登记一个排得更前的空占位。

   - `check_ui_words.py` 禁"工作区"，后跟 `\` 或 `/` 的目录名放过；扫描加了 P-20 改的词条表；零命中。
