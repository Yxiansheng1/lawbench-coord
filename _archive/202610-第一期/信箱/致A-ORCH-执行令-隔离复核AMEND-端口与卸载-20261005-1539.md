## 必修
1. **F1 P1 Host 端口写死 127.0.0.1:19387**（`apps/desktop-host/src/index.ts:33` `--port 19387`，cordis.patch.yml 未覆盖）。锁分开后两程序能同时启动，后起的 Host 因 EADDRINUSE 启动失败弹致命错误；两边关窗都留托盘，所以"另一个还开着"很常见。**修法：装好的包用 `--port 0`**（`lawbench-request-policy` 按 `ctx.webServer.port` 放行，不依赖 19387——你核一遍还有谁写死 19387：dsh-ext、acceptance 脚本、文档、自检）。开发期可保留 19387。**冒烟项**：先用 node 在 127.0.0.1:19387 开一个监听占住端口，再启动装好的包，须能进主窗口。
2. **F2 P1 卸载程序仍清原版目录、不清我方新目录**：`uninstall.nsh un.CleanData` 删 `\`（= `%APPDATA%\@deepseek-ai\dsh-desktop`，隔离后只属原版）与 `\<updater 缓存>`；我方 `%APPDATA%\lawbench-desktop`（含 `Partitions/retainer`，可能有委托人信息）和 `%LOCALAPPDATA%\lawbench\dsh-home` 卸载后留着。**主编排定**：
   - 卸载清理目标改为 `%APPDATA%\lawbench-desktop` **和** `%LOCALAPPDATA%\lawbench\dsh-home`（profile/锁/索引都可重建；会话记录在案件文件夹不受影响）；`%LOCALAPPDATA%\lawbench` 其余（settings、logs）维持现行为。
   - **不再删** `APP_PACKAGE_NAME` 目录与 updater 缓存目录本身。
   - `lawbenchAfterInstall` 对 updater 缓存里的 `installer.exe`：只删**本次安装写的那个**（比对大小 == 本安装包大小，或 mtime 在本次安装开始之后），别的不碰；`DSH_INSTALLER_LOG_DIR` 若也指向原版目录，改到 `%LOCALAPPDATA%\lawbench\installer-logs`。
