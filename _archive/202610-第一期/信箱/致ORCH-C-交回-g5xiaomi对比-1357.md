## 令里点名的四项
1. **水印页复读**：没有了。9-30 那页 4903 字的讯问笔录第 1 页，这次输出 177 字，相似度 1.000。
2. **每页秒数**：水印页从 26 秒降到约 5 秒；无水印页差不多（6.0 → 5.1）。
3. **页眉页脚确实丢了**。bench 的样张没有页眉页脚，所以另做了一页虚构的探针（扣押物品清单）。页眉的"（2026）虚刑初字第0123号"、"虚构市虚构区人民法院"和页脚的"第 3 页 共 12 页"，三处都没出现在结果里；正文和表格内容全对。
4. **表格是 OTSL 标记**，原样片段：
   ```
   <fcel>序号<fcel>物品名称<fcel>数量<fcel>备注<nl><fcel>1<fcel>手机（黑色）<fcel>1部<fcel>已封存<nl>…<fcel>3<fcel>现金<fcel>人民币86,420元<ecel><nl>…
   ```
   - `<fcel>` 是有内容的单元格，`<ecel>` 是空单元格，`<nl>` 是一行结束；
   - 没有外层标签，也不是 Markdown 表格。
5. **`backend` 字段**：实测一条识别结果，是 `llama.cpp/vulkan:xiaomi-ocr-0`。

## 两件事的建议（请定）
- **OTSL 转 Markdown：建议做。**
  - 改哪：`prep395\prep395\backends.py`。xiaomi 模板的识别结果返回前，把连续的 `<fcel>…<nl>` 行转成 Markdown 表格；合并单元格标记 `<lcel>`、`<ucel>`、`<xcel>` 按空单元格处理。
  - 多大：约 25 行，加一条用例。
  - 部署：做完要用户在 395 上再拷一次源码、重跑一次 `install.ps1`。
  - 不做的后果：材料文本里的表格是一串尖括号标记，检索和引用还能用，但律师读着费劲，27B 也可能读错行列。
- **页眉页脚丢失：建议先记为已知限制。**
  - 理由：引用用的页号是我们自己按 PDF 页序编的【第N页】，不靠识别出来的页码；案号一般正文里也有。
  - 想找回来的办法：每页再用模型卡的另一句提示词 `Extract the text in the image.` 识别一遍，只取正文之外的部分，每页多约 5 秒。
  - 那句提示词会不会输出页眉页脚**没有验证**：开发机改不了 395 上的提示词，要先在 395 上试一次才知道。
